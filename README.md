# DigiTools | Modern Digital Marketplace

**DigiTools** is a high-performance, aesthetically pleasing digital products landing page. Designed for modern digital tool marketplaces, it offers a seamless shopping experience with a focus on speed, responsiveness, and user engagement.

## Features

### 1. Dynamic Shopping Experience
A real-time shopping cart system that allows users to browse and add digital products seamlessly. Built with state-of-the-art React hooks for a smooth, lag-free experience.

### 2. Pixel-Perfect Responsive Design
Crafted using Tailwind CSS and DaisyUI, the interface adapts beautifully to any screen size—from smartphones to large desktop monitors—maintaining its premium look and feel.

### 3. Efficient Data Loading
Utilizes React Suspense and asynchronous fetching for non-blocking data loading. Product data, service steps, and pricing plans are loaded dynamically from JSON sources, ensuring lightning-fast initial page loads.


## Tech Stack

- Core Framework: React 19
- Build Tool: Vite
- Styling: Tailwind CSS 4 & DaisyUI 5
- Icons: Lucide React,Font Awesome
- Notifications: React Toastify
